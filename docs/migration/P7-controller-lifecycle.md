# P7：控制器生命周期迁移（第一批）

## 已进入正式路径

- AI Batch Coordinator 接管字幕获取、PRE、POST 阶段的执行身份、状态与停止校验。被替换的阶段即使迟到完成，也不能继续提交下一阶段。
- Studio Interaction Controller 接管输入框伸缩、命令菜单键盘导航、发送及错误回调；绑定可解绑，重复绑定会清理旧监听器；输入法确认不触发发送。
- Knowledge Controller 接管回答请求生命周期和锚点最新节点选择。停止后保留部分回答并标为 stopped；旧请求的 finally 不能清理新请求。

## 尚需继续迁移

这批是生命周期切分，并非三个业务域全部迁出。AI 缓存分区、任务计划、单模型重试与持久化仍由 compat 调用；Studio 委派点击、停止按钮和菜单动作仍在 compat；Knowledge 树交互、锚点创建、展示与写入编排仍在 compat。后续沿这三个 Controller 扩展业务所有权，不再创建平行执行路径。

## 验证

新增停止后阶段迟到、替换请求、失败后显式重试、跨锚点选择四个测试。保留原有单元和 Golden 检查；不运行浏览器回归。
