# Bili SubBatch v6.10.1

This release consolidates the Studio UI migration while preserving the existing userscript identity and compatibility behavior.

## Changes
- Extracted shell geometry, state, pointer, chrome, markup, and base CSS into dedicated TypeScript modules.
- Extracted AI, subtitle library, Knowledge, and Settings workspace markup.
- Moved shared, workspace-specific, rich reading, Folio, and late-override CSS out of the maintained compatibility body while preserving cascade order.
- Added workspace markup/style regression contracts and retained the historical Golden baseline.
- Updated the released userscript metadata and runtime version to 6.10.1.

## Verification
- TypeScript typecheck, lint/boundary checks, complete Vitest suite, Full userscript build/verification, and Pure bundle build/verification passed on PC1.
- Browser-based panel and navigation checks were run against the previously installed 6.9.17 script. A full browser end-to-end test of the newly installed 6.10.1 userscript was not completed.

## Installation
Install `loop-bilibili-flow.user.js` from this release using Tampermonkey or a compatible userscript manager. The `name` and `namespace` remain unchanged for upgrade compatibility. The experimental Pure bundle is not a replacement for the full userscript.

## Known migration scope
Compatibility business controllers and event handlers have not yet been fully extracted. Their preserved compatibility implementation remains the production behavior in this release.
